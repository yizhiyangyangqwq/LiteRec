# LiteRec 宣传片分镜脚本（Windows 11 风格）

> 目标平台：B 站（16:9，1920×1080 或 2560×1440）
> 时长：60 秒主片 + 15 秒短版（动态/短视频复用）
> 视觉风格：Windows 11 宣传片 —— 柔和渐变、玻璃质感、体积光、浅景深、克制的运镜

---

## 核心原则（决定了成片是否"像官方"）

| 原则 | 说明 |
| --- | --- |
| **AI 只做氛围，不做界面** | AI 视频生成不了准确的 UI 和文字，会糊、会乱码。所有界面用**真实录屏** |
| **文字全部后期加** | 92 KB、功能名、GitHub 地址，一律在剪映/PR/AE 里打字，别让 AI 生成 |
| **单镜头 4–6 秒** | AI 视频工具普遍单次生成 4–5 秒，分镜要短，靠剪辑连起来 |
| **视觉锚点统一** | 全片只用一组元素：蓝色光、玻璃、浅景深、黑/白背景 |
| **前 3 秒必须有钩子** | "92 KB" 要在开头就砸出来，B 站用户划走极快 |

- **画面**：纯黑背景，一粒透明玻璃正方体悬浮，一束蓝光从上方射入，玻璃内部折射出细碎光斑，镜头极缓慢推进

- **音效**：一声清脆的"叮"+ 低频铺底
- **来源**：AI 生成

## 15 秒短版结构

只保留四个镜头，节奏更快：

| 时间 | 内容 |
| --- | --- |
| 0–3s | 01 玻璃方块 + `92 KB` |
| 3–7s | 06 录游戏真实画面 + `满帧不卡` |
| 7–11s | 07 声波 + `系统声音一起录` |
| 11–15s | 08 数字定格 + 片尾链接 |

## 制作清单

**画面**
- 分辨率 1920×1080（或 2560×1440），帧率 30
- 主色：Windows 蓝 `#0067C0`，辅助：白、浅灰、黑
- 字体：标题用 `微软雅黑 Bold` 或 `Segoe UI Variable`，正文细体
- 全片保持大量留白，宁可空，不要挤

**声音**
- 音乐：搜「极简 科技 钢琴 上升 氛围」，B 站创作中心有免费音频库
- 关键节点配单点音效（叮、唰、定音鼓），不要全程铺满
- 人声可选；若加，语速慢、句子短

**节奏**
- 前 3 秒决定完播率，`92 KB` 必须第一个出现
- 每 4–6 秒换一个镜头，不要一个镜头拖 10 秒
- 转场用「叠化」和「白闪」，不要花哨特效

## 一个加分项

视频里可以加一句字幕：

> **「这个演示视频里的录制片段，就是用 LiteRec 自己录的。」**

这是最强的可信度证明，而且只有真做过的人才说得出来。

## 常见翻车点

| 问题 | 原因 | 避免方法 |
| --- | --- | --- |
| UI 糊成一团 | 让 AI 生成界面 | 界面全部真实录屏 |
| 文字乱码 | AI 生成文字 | 文字后期打字 |
| 各镜头风格不一 | 提示词差异太大 | 固定一组关键词复用 |
| 看起来像 PPT | 全是静态图 | 每个镜头都要有运镜或光动 |
| 没有人味 | 全程无人声、无署名 | 片尾一定要放作者名 |
